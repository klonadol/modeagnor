# AGNOR workspace

Папка подготовки проекта AGNOR (Minecraft 1.21.1 / Fabric / Java 21).

- `incoming/` — файлы и архивы для первичной сортировки.
- `assets/models/` — локальные тестовые модели. Не добавлять в публичный Git без проверки прав.
- `assets/textures/` — тестовые текстуры с указанием источника и лицензии.
- `builds/` — локальные сборки и результаты прототипов.
- `reports/` — отчёты по техническим проверкам.

Исходный репозиторий: https://github.com/klonadol/modeagnor

## Уже найдено на компьютере

- Blender 5.2.0 LTS: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`.
- OpenJDK 21.0.7 LTS из среды ElyPrismLauncher/Pinecone MC: `%APPDATA%\ElyPrismLauncher\java\java-runtime-delta`.
- Git установлен. Для сборки использовать Gradle Wrapper из репозитория, не устанавливать глобальный Gradle без необходимости.

Репозиторий клонирован в `modeagnor/`; там уже есть локальный Fabric bootstrap и Gradle Wrapper. Навигация — [УКАЗАТЕЛЬ](УКАЗАТЕЛЬ.md) и [карта проекта](modeagnor/docs/PROJECT_MAP.md). Ключи API, пароли и личные данные в эту папку и Git не помещать.
