# ADR-0001: Целевая платформа Minecraft

- **Статус:** Accepted
- **Дата:** 2026-11-02
- **Область:** Build / Runtime / Compatibility

## Контекст

Проекту нужна стабильная база для сложного Fabric-мода с 3D-моделями, сетевым взаимодействием, постоянными данными и интеграциями с другими модами. Требуется сохранить мультиплеерную архитектуру с самого начала.

## Решение

Целевая версия первой реализации:
- Minecraft 1.21.1;
- Fabric Loader;
- Java 21.

GeckoLib можно оценить для вспомогательных моделей и анимаций, но он не выбран основным renderer гладких polygon-mesh персонажей. Основной renderer остаётся открытым и выбирается после минимального прототипа на готовой модели.

## Рассмотренные альтернативы

- Fabric 1.21.11 — отложен, чтобы не распылять разработку на несколько версий.
- Одновременная поддержка 1.21.1 и 1.21.11 — не входит в начальный объём.
- Forge/NeoForge — не выбраны для первого проекта.

## Последствия

- Gradle/Loom, Yarn/Mojang mappings и версии библиотек должны быть согласованы в начальном build spike.
- Портирование на другие версии рассматривается только после рабочего релиза или по отдельному ADR.
- Совместимость с модами проверяется на выбранной комбинации loader/game/library, а не предполагается по названию библиотеки.

## Проверка

**Bootstrap подтверждён 2026-11-04:** Minecraft 1.21.1, Java21, Loader 0.16.10, API 0.102.1+1.21.1, Loom 1.7.4, Yarn 1.21.1+build.3, Wrapper8.8; build/integrated/dedicated evidence — [отчёт 004](../reports/2026-11-04-004-phase-0-client-network.md). Это не доказательство совместимости будущего renderer. GeckoLib не является обязательной зависимостью bootstrap; выбор backend проверяется в P3.1.
