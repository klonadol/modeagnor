# ADR-0005: Интеграции с Create и другими модами

> Фазовые предписания пересмотрены 2026-11-05 в [ADR-0009](ADR-0009-dependency-driven-plan.md); функциональное решение сохраняется.

- **Статус:** Accepted
- **Дата:** 2026-11-02
- **Область:** Compatibility / Extensibility

## Контекст

В дальнейшем пользователь хочет добавить Create и, возможно, другие моды. Первая версия Агнора должна быть законченной самостоятельно и не должна зависеть от наличия внешних модов.

## Решение

Основной Agnor Core не имеет обязательной зависимости от Create. Взаимодействие с игровыми объектами проектируется через общий Action / Interaction API.

Для Create и других модов могут появляться отдельные интеграционные addon-моды. Addon:
- обнаруживает доступную зависимость и её версию;
- регистрирует специфические типы целей, событий и действий;
- проверяет условия безопасного исполнения;
- не меняет базовый Character Runtime;
- может отсутствовать без нарушения работы Агнора.

## Последствия

- Совместимость каждого addon проверяется отдельно для конкретной версии Minecraft и loader.
- Не следует обещать поддержку Create на Fabric 1.21.1 до проверки реальной доступной сборки.
- Основные игровые действия NPC должны работать без сторонних контентных модов.
- Интеграционный API должен быть стабильным и документированным до разработки первого addon.

## Когда фиксируется публичный Addon API

Внутренняя модульная изоляция и точки расширения могут появляться в базовом каркасе (P1), но публичный API нельзя замораживать до определения реальных контрактов действий, целей и событий.

- P7 создаёт и проверяет семантику Action/Goal/Event API на рабочем runtime: Goal Scheduler, Bot, Action Validator/Executor и World Observer.
- P9 проводит compatibility hardening, versioning и freeze публичного Addon API.
- P10 реализует конкретные addons (включая возможный Create adapter) поверх зафиксированного API.

Это сохраняет обязательное требование: API должен быть стабильным и документированным до первого addon, но не заставляет угадывать его semantics до появления базовых функций, которые addon будет расширять. Create compatibility по-прежнему проверяется на конкретной версии Minecraft/Fabric/Create и не подразумевается самим наличием API.

## Проверка

**Не выполнена.** Ни Create adapter, ни совместимый набор Create/Fabric 1.21.1 не проверялись в этом репозитории.
