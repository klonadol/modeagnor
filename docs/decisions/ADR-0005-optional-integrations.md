# ADR-0005: Интеграции с Create и другими модами

- **Статус:** Accepted
- **Дата:** 2026-11-02
- **Область:** Compatibility / Extensibility

## Контекст

В дальнейшем пользователь хочет добавить Create и, возможно, другие моды. Первая версия Агнора должна быть законченной самостоятельно и не должна зависеть от наличия внешних модов.

## Решение

Основной Agnor Core не имеет обязательной зависимости от Create. Взаимодействие с игровыми объектами проектируется через общий Action / Interaction API.

Для Create и других модов могут появляться отдельные интеграционные addon-моды. Addon:
- обнаруживает доступную зависимость и её версию;
- регистрирует специфические типы целей, событий и действий;
- проверяет условия безопасного исполнения;
- не меняет базовый Character Runtime;
- может отсутствовать без нарушения работы Агнора.

## Последствия

- Совместимость каждого addon проверяется отдельно для конкретной версии Minecraft и loader.
- Не следует обещать поддержку Create на Fabric 1.21.1 до проверки реальной доступной сборки.
- Основные игровые действия NPC должны работать без сторонних контентных модов.
- Не проектировать заранее универсальный публичный API для всех возможных addon. Когда появится конкретная интеграция, определить минимальный интерфейс, нужный именно ей, и стабилизировать его вместе с реализацией.

## Проверка

**Не выполнена.** Ни Create adapter, ни совместимый набор Create/Fabric 1.21.1 не проверялись в этом репозитории.
