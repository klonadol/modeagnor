# Asset Replacement Register

Этот реестр содержит временные модели и другие 3D-ассеты, которые используются только для закрытой разработки и должны быть заменены или удалены до публичного релиза.

**Release gate:** перед выпуском реестр должен быть пуст по статусам `TEMPORARY_RESTRICTED` и `REPLACEMENT_REQUIRED`. Не переносите сами модельные файлы в этот каталог или Git.

## Статусы

- `TEMPORARY_RESTRICTED` — временный ассет используется в локальном прототипе; замена обязательна.
- `REPLACEMENT_REQUIRED` — использование прекращено, но релизная проверка/очистка ещё не подтверждена.
- `REPLACED` — заменён разрешённым ассетом; указать ссылку на замену и подтверждение прав.
- `REMOVED` — удалён из рабочего проекта; подтвердить отсутствие в сборках и артефактах.

## Чек-лист перед релизом

- [ ] Проверить все строки со статусами `TEMPORARY_RESTRICTED` и `REPLACEMENT_REQUIRED`.
- [ ] Заменить их на собственные или разрешённые ассеты либо удалить.
- [ ] Проверить Git history, JAR, Content Packs, CI artifacts и релизные архивы на отсутствие исходных файлов.
- [ ] Проверить, что серверная синхронизация не содержит временных ассетов.
- [ ] Указать доказательство проверки и перевести записи в `REPLACED` или `REMOVED`.
- [ ] Только после этого закрыть release gate.

## Правила заполнения

1. Создавать запись до импорта временного файла в проект.
2. Сохранять исходную страницу и прямую download URL, если источник её предоставляет.
3. Записывать SHA-256 фактически скачанного файла, а не только архива/страницы.
4. Не хранить здесь секреты, персональные данные или сам ассет.
5. Если источник запрещает автоматизированную загрузку, не обходить это ограничение; использовать официальный доступный способ.
