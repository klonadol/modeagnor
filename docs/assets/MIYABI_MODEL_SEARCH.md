Отсеяны одноимённые оригинальные VRChat avatars, image LoRA, статуэтки/STL и chibi: они не соответствуют запросу на качественную анимационную Hoshimi Miyabi. Telegram-репаки найдены поиском, но не дают проверяемого происхождения/права.

В пользовательской коллекции `assets/models/разное/8375139245952109414.vrm` есть rig с823skin joints/44morphs, сходный по цифрам с T-T. Метаданные title/author/version равны `1`; идентичность Мияби и происхождение **не доказаны**. Не переименовывать автоматически. Исходник не менялся.

Решение: ссылки сохранены; новые assets не активированы. P3.4 продолжает ту же Firefly, что принята в P3.3. Замена rig без повторной приёмки нарушила бы последовательность проверки gait→secondary physics. Для будущего выбора сначала локальная front/side/three-quarter QA и проверка лицензии/экспорта; Blender/VRChat controllers не переносятся в host Java автоматически.
