## 1. Цель и исходное требование

Пользователь уточнил целевой уровень: «лучшее из лучшего» и физика движений в духе Zenless Zone Zero (ZZZ).

Нужно было определить, что означает эта цель для рига, mesh, анимационного стека, мимики и secondary physics, а также проверить актуальные варианты GLB renderer для Fabric 1.21.1.

## 4. Техническая оценка библиотек

### GemRender

Публичное описание проекта заявляет GLTF 2.0, GPU skinning, morph targets, animation blending, body-part masks, additive layers и Fabric target для Minecraft 1.21.1. Это делает GemRender перспективным кандидатом для benchmark.

Ограничения и вопросы:
- Нужна проверка того, как публичный API позволяет менять morph weights динамически, а не только проигрывать импортированные анимационные каналы.
- Нужна проверка custom procedural pose / IK и расширяемости анимационного pipeline.
- Проект молодой; требуется тест стабильности и регрессий на конкретной версии.
- Нужно отдельно проверить зависимости Flywheel, совместимость с используемыми рендер-модами и лицензионные последствия для распространения Агнора.
- Встроенной ZZZ-подобной системы волос/одежды из документации не следует.

Ссылки:
- https://github.com/Warfactory-Official/GemRender
- https://www.curseforge.com/minecraft/mc-mods/gemrender

### BlendLib

Публичный Beta.3 заявляет Fabric runtime для Minecraft 1.21.1 и GLB pipeline. Документированная capability matrix описывает skinned GLB, однако:
- strict v1 не поддерживает Morph Targets / Shape Keys;
- skinning в описанном стандартном пути CPU-based;
- максимум четыре эффективных skin weights на вершину;
- процедурные модификаторы и физические эффекты должны быть запечены в поддерживаемую геометрию/анимацию;
- публичный обычный entity pose callback ограничен вращением узлов, без общей процедуры изменения translation/scale.

Это полезный ориентир и потенциальный базовый pipeline для части задач, но по текущей документации не покрывает весь целевой профиль самостоятельно.

Ссылки:
- https://github.com/LIy-hub/BlendLib-Public
- https://github.com/LIy-hub/BlendLib-Public/blob/main/docs/developer-handbook.md
- https://github.com/LIy-hub/BlendLib-Public/blob/main/docs/release/blender-export-checklist-v1.md

### Zenless Zone Zero

В опубликованном интервью команда анимации ZZZ описала волосы как одну из главных технических сложностей. В качестве рабочего подхода упоминались Maya Dynamics Evaluator, интеграция динамики со skinning, лёгкие внешние инструменты для менее сложных сцен и ручная настройка сложных action-сцен покадрово.

Вывод для Агнора: ориентироваться нужно на hybrid art-directed motion — авторские клипы + процедурные контроллеры + ограниченная secondary physics + ручная коррекция, а не на полную симуляцию всей модели.

Источник:
- https://s.inside-games.jp/article/2024/12/12/162341.html

## 6. Принятые требования

- Полноценная гладкая skinned polygon mesh.
- Развитый humanoid rig, пальцы и face rig.
- Morph targets / blend shapes для мимики и артикуляции речи.
- Смешиваемая авторская анимация, layer masks, additive layers и crossfades.
- Процедурный look-at, IK, микродвижения и коррекция позы.
- Secondary physics волос, подвесок и выбранных элементов одежды.
- Упрощённые collision proxies, ограничения и демпфирование.
- Blender как authoring tool; GLB/glTF как предпочтительный runtime interchange format после проверки функций.
- Конкретный renderer не выбран; GemRender и другие варианты должны пройти прототип.
- Хост остаётся авторитетным для gameplay. Визуальная high-frequency secondary physics может быть клиентской, если не влияет на gameplay; точная политика требует профилирования и мультиплеерного теста.

## 8. Оставшиеся риски

- Наличие поддержки morph targets в импортёре не гарантирует удобный runtime API для управления лицом по значениям эмоций.
- Renderer и physics backend могут потребовать отдельного собственного слоя.
- Высококачественная модель требует качественного topology, skin weights, facial shapes и авторских анимаций; одна библиотека не обеспечивает художественное качество.
- Реалистичная cloth simulation может быть слишком дорогой для нескольких NPC; начальный профиль должен опираться на skeletal secondary motion и ограниченные solver chains.
- Зависимости, лицензии, shader compatibility и API stability нужно подтвердить на фактической сборке.

## 9. Итог и следующий шаг

Зафиксирован высокий визуальный целевой уровень, аналогичный современной stylized anime action-RPG, с гибридной вторичной физикой в духе ZZZ. Окончательный renderer **не выбран**.

Следующий шаг в Фазе 0: создать тестовый Fabric 1.21.1 client и минимальную skinned anime-модель, а затем выполнить сравнительный spike GemRender vs собственный GLB renderer (BlendLib может быть проверен как контрольный вариант, но его текущие ограничения по morph targets должны учитываться). Только после реального теста принимать решение о зависимости.
