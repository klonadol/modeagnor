## 8. Риски и ограничения

- Это документационная база, а не реализация мода.
- Совместимость GeckoLib, конкретные версии Fabric API/Loom/mappings и сборка пока не проверены.
- Каталог `mods/agnor/` — согласованная цель, но его поведение и права записи должны быть проверены прототипом.
- Форматы Content Packs, схема SQLite и векторный индекс ещё не утверждены окончательно.
- Определение игрового «дня» для сводки требует отдельного решения.
- Совместимость Create с Fabric 1.21.1 не проверялась.
- Сборка, тесты, клиент-серверный сценарий и runtime-поведение **НЕ ПРОВЕРЕНЫ**.
