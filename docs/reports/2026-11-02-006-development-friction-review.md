# Отчёт 006: Упрощение процесса разработки и ранних этапов

- **Дата:** 2026-11-02
- **Статус:** Done (документация обновлена; реализация и runtime не менялись)
- **Ветка:** `main`
- **Задача:** убрать преждевременные требования и бюрократию, не ослабляя базовую безопасность

## Что изменено

- Восстановлены случайно удалённые ранее описания Фаз 3–9 roadmap.
- Roadmap упрощён: сначала рабочий сценарий, затем наращивание возможностей; недельный прототип — ориентир, а не жёсткий дедлайн; полный набор проверок выполняется перед соответствующим выпуском.
- Content Packs начинают с локальных папок. ZIP-импорт, hot reload, автоматическая загрузка и сетевой sync откладываются до реальной необходимости.
- Поддержка модели на раннем этапе проверяется по функциям, нужным текущей задаче. Подробный capability report оставлен для контента финальной версии/распространяемых пакетов.
- Временные модели разрешены в локальных dev-сборках, JAR и Content Packs; поскольку GitHub-репозиторий публичный, сами файлы в него не коммитятся и не попадают в публичные релизы/синхронизацию.
- Renderer оценивается поэтапно: загрузка и skinning сначала, IK/лицо/физика/сеть — по мере реализации.
- Не требуется проектировать стабильный универсальный API для будущих addon до появления конкретной интеграции.
- Отчёты и ADR больше не требуются на каждую мелкую задачу. Небольшие изменения можно объединять в commit messages и записи журнала.
- Asset Replacement Register остаётся простым списком; временные модели заменяются только перед финальным релизом полной версии после переноса авторского мира.

## Что оставлено обязательным

Это базовая защита, а не преждевременная «релизная чистка»:
- секреты и API-ключи не попадают в Git или клиентам;
- сервер проверяет отправителя, права и действия, меняющие мир;
- Content Packs не исполняют произвольный Java-код/скрипты;
- временные модели можно использовать в локальных dev-сборках, JAR и Content Packs; поскольку репозиторий публичный, сами файлы не коммитятся в Git и не включаются в публичные пакеты/релизы или сетевую синхронизацию;
- данные миров и игроков остаются изолированными.
